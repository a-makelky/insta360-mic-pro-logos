# How To Load A Logo Onto Insta360 Mic Pro

The finished files are already sized for the Mic Pro transmitter display.

## Use Color

Use a file from `logos/<brand>/color/` or download `downloads/insta360-mic-pro-logos-color.zip`.

Color is supported by the Mic Pro's 6-color E-Ink screen, but E-Ink is not a phone display. Some colors may look less saturated.

## Use High Contrast

Use a file from `logos/<brand>/mono/` or download `downloads/insta360-mic-pro-logos-high-contrast.zip`.

This is the most reliable option when readability matters more than brand color.

## Loading Steps

1. Download the PNG you want.
2. Save it to your phone album.
3. Open the Insta360 app.
4. Open the Mic Pro E-Ink/custom wallpaper settings.
5. Choose the image from your phone album.
6. Preview it on the transmitter.

If a color logo looks muddy on the actual mic, switch to the high-contrast version.

## Device Target

- Device: Insta360 Mic Pro transmitter
- Display: 1.22 in 6-color E-Ink
- Resolution: 240 x 208 px
- Pixel density: 197 PPI
- File format in this kit: PNG with transparent background
