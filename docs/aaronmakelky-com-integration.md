# aaronmakelky.com Integration

Recommended public URL:

```text
https://aaronmakelky.com/tools/insta360-mic-pro-logo-kit
```

Use `aaronmakelky.com` as the canonical discovery page and this GitHub repo as the public source library.

## Page Jobs

- Explain what the kit is.
- Show searchable logo cards.
- Let people download individual PNGs.
- Link to ZIP downloads.
- Link to the AI Tools Excalidraw library.
- Link to GitHub issues for logo requests.
- Link to the repo for pull requests.

## Why This Split Works

The website gets search traffic and domain authority.

GitHub handles the community workflow: issues, pull requests, source history, and releases.

It is the same split as field and film room. The website is where people see the play. GitHub is where the playbook gets edited.
